# Parametric Spur Gear – Lau Code - IceSL

This project demonstrates a parametric spur gear designed using Lau coding, showcasing real-time geometry changes with adjustable parameters.

![Spur Gear Demo](https://github.com/M-H-JOMAA/Cyber-Physical-Production/blob/main/Tweaks.gif)

## 🔧 Features
- Fully parametric spur gear model
- Lau code-based design for dynamic adjustments
- Easily tweak number of teeth, pitch diameter, and more
- Ready for additive manufacturing or simulation
